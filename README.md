# BRAIN Portal

[![Public Site](https://img.shields.io/badge/Public%20Site-brain.bnl.gov-blue)](https://brain.bnl.gov)
[![Licensing: BSD-3-Clause + CC BY 4.0](https://img.shields.io/badge/Licensing-BSD--3--Clause%20%2B%20CC%20BY%204.0-orange)](LICENSING.md)


**BRAIN (BRookhAven INference)** is Brookhaven National Laboratory's
secure platform for running generative machine learning models on Lab
infrastructure. It provides access to open-weight models through a chat
interface and an OpenAI-compatible API, keeping data within the Lab
network.

This repository contains the BRAIN Portal, a static website that serves as
the entry point to the platform. It consists of:

- **Landing page** — platform overview and available models.
- **Leaderboard** — benchmark results for the served models.
- **User guides** — instructions for using the chat interface and the API.
